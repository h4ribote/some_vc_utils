# ダッシュボード

ダッシュボードは `api` が提供し、Cloudflare Tunnel の公開ホスト名 (`SVU_PUBLIC_BASE_URL`) で開く。

## ログイン

Discord の OAuth2 (`identify` と `guilds` のスコープ) でログインする。

1. `/login` がログインの状態を記録して Discord の認可画面に送る。状態は10分間、一度だけ使える。
2. Discord が `/auth/callback` に戻すと、ユーザーの Discord トークンを `SVU_SECRET_KEY` から導いた鍵で暗号化してセッションに保存し、セッションの Cookie を発行する。
3. セッションは7日間有効である。Cookie は HttpOnly、Secure、SameSite=Lax で、データベースにはその SHA-256 だけが残る。

`/logout` でセッションを削除する。Discord がユーザーのトークンを拒否するようになったセッションは、その時点で削除され、ログインし直しになる。

## 権限

| ページ | 見られる人 |
| --- | --- |
| サーバー一覧、サーバーのページ | そのサーバーの所有者、または Manage Server か Administrator の権限を持ち、Bot が参加しているサーバー |
| 個人設定 | ログインした本人 |
| 管理 | `SVU_ADMIN_IDS` に含まれるユーザー |

サーバーと権限の一覧は Discord の `/users/@me/guilds` から取得し、60秒ごとに取り直す。権限を失ったサーバーは、その後の最初の読み直しから操作できなくなる。
見られないページと操作できないサーバーへのフォームは、存在しないページと同じ 404 で答える。

すべてのフォームはセッションごとの CSRF トークンを要求し、ブラウザが `Origin` を送る場合はそれが `SVU_PUBLIC_BASE_URL` と一致することを確かめる。
応答には、スクリプトを一切許可しない Content-Security-Policy と、フレームへの埋め込みを禁止するヘッダーが付く。

## 画面

### サーバー

* 支払い元: Bot のウォレットとサーバーの発行枠を切り替える。発行枠への切り替えは発行の許可を申請し、承認用のコマンドを表示する。
* 報酬の通貨: 支払い元が Bot のウォレットのときに設定する。存在しない通貨は拒否される。
* プール残高: 通貨ごとの残高。請求による入金と、自分のウォレットへの引き出しができる。
* 報酬ルール: `message` と `server_join` の報酬額とクールダウンを保存、削除する。
* 最近の操作、最近の支払い、プールの記録。

設定の変更は、操作した人とともに監査ログに記録される。

### 個人設定

`/send` のメッセージを DM で受け取るかどうかを切り替え、自分が実行した操作の状態を確認する。

### 管理

* VirtualCrypto アプリの Webhook の URL と、VirtualCrypto が最後に Webhook を確認できた日時、確認できなかった日時。
* 対応が必要な支払い: 結果が分からないまま5日経った支払いと、拒否された返金。結果が分からない支払いは、VirtualCrypto の履歴を確認したうえで「支払い済み」か「支払われていない」を記録する。「支払われていない」は補償を行う。
